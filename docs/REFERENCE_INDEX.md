## Internal source categories

The portfolio artifacts above were compiled from authoritative GoreeCloud records covering:

- Overview, vision, mission, principles, objectives, technology independence, and public impact.
- Platform architecture, platform layers, integration, and the Native Applications Plan.
- Repository policy, GitHub profile, public-website portfolio, and project specifications.
- The authenticated GitHub organization inventory and the GoreeCloud Drive category map.

Individual internal source links are intentionally kept out of this repository. Use the Google Sheet’s **Key Documents** and **Drive Reference Map** tabs when authenticated access is appropriate.

## Maintenance rules

1. Keep volatile inventory details in the Google Sheet and concise summaries in this repository.
2. Link to the most specific authoritative record instead of copying it.
3. Mark planned work clearly; repository presence does not prove deployment or production readiness.
4. Review visibility, classification, and link access before publication.
5. Update this page when an authoritative record moves or is replaced.
