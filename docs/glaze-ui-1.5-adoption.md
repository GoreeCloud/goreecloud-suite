# Glaze UI 1.5.0 adoption

GoreeCloud Suite targets Glaze UI **1.5.0 Stable** from `GoreeCloud/goreecloud-glaze-ui` revision `2c5078410d022eba683c8e029bc3cafe773df0b7`. The production stylesheet is vendored in-repository, uses the Design Center Stable web layer order, excludes Candidate/Wearable layers, and adds Suite-specific material, interaction, focus, motion, and card mapping without a cross-domain runtime dependency.
