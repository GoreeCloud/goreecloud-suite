# Glaze UI 2.1.0 adoption

GoreeCloud Suite targets **Glaze UI 2.1.0 Stable** from `GoreeCloud/goreecloud-glaze-ui`, anchored to Stable promotion reference `c49113eb8b93c267613fdf1bbca1f814495acad7`.

The public Suite build publishes a same-origin 2.1 web layer and normalizes the deployable HTML onto the current Stable contract. The integration follows the 2.1 material rule **Content is solid. Interaction is glazed.** Durable application, capability, and principle content is rendered on solid Surface material; Soft Glaze and Glaze are reserved for navigation, controls, hero interaction, and other transient/interactive surfaces.

The consumer contract supports Clear, Balanced, and Solid clarity; Comfortable, Standard, Compact, and Far View density; a 56px effective Touch Assistance floor; large-text compact-density fallback; reduced motion; reduced transparency; increased contrast; forced colors; keyboard focus; same-origin non-backdrop fallback; and deterministic reduced-material performance behavior.

The integration adds no cross-domain UI runtime dependency. Glaze UI controls presentation and interaction only; application lifecycle, Privacy Shield, Wardveil Security, Everkeep, Mesh, and GoreeCloud Identity state remains producer-authoritative and evidence-scoped.

Glaze UI 2.0 evidence remains historical migration input only. Source/build validation and rendered Cloudflare Pages acceptance are separate gates. This repository must earn its own 2.1 production acceptance for the exact deployed revision before the production site is represented as accepted.
