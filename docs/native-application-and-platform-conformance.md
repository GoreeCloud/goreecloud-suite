# GoreeCloud Suite Native Application and Platform Conformance

Effective August 24, 2026, every GoreeCloud Suite application must be built as an original native GoreeCloud implementation from the ground up.

Critical supporting dependencies may remain external when narrowly justified, including WireGuard, cryptographic/encryption primitives, standards/protocol libraries, platform interfaces, database engines, codecs, and comparable foundational necessities.

Every Suite application must integrate and remain current with Glaze UI, Wardveil Security, Privacy Shield, and Everkeep. These systems are mandatory functional dependencies. Stable qualification is blocked if any applicable integration is missing, stale, incompatible, cosmetic-only, or unvalidated.

Application repositories must carry implementation and validation evidence appropriate to their lifecycle stage and must update their integrations as the shared platform contracts evolve.
